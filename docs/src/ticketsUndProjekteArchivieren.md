# Projekte archivieren
Ein Projekt kann archiviert werden, indem das gewünschte Projekt
entsprechend in der Projektübersicht ausgewäht und zu den Einstellungen
navigiert wird. Unten findet sich ein entsprechender Button. Admins 
können hier auch das Löschen eines Projektes bewirken, dies ist endgültig!
![1](\Bilder\ProjektArchivieren.png)
# Projekte aus Archiv verschieben
Die archivierten Projekte können von Admins über die Navigaton
am linken Bildschirmrand aufgerufen werden.
![2,1](\Bilder\ArchivierteProjekteFinden.png)

Indem das gewünschte Projekt ausgewählt und zu den Einstellungen
navigiert wird, kann die Möglichkeit gefunden werden, das Projekt
aus dem Archiv wieder in die aktiven Projekte zu verschieben oder
zu löschen. Eine Löschung ist hierbei endgültig.
![2,2](\Bilder\ProjekteAusArchivVerschieben.png)
# Tickets archivieren
Um ein Ticket zu archivieren, muss es in der Ticketübersicht
ausgewählt werden. Hier findet sich auf der rechten Seite die
Option zum Archivieren. Administratoren können hier außerdem auch
das Ticket löschen. Diese Option ist endgültig!
![3](\Bilder\TicketsArchivierenUndLöschen.png)
# Archivierte Tickets wiederherstellen
Um ein archiviertes Ticket wiederherzustellen, muss zu den
archiverten Tickets im Projekt navigiert werden (Projekt->Tickets).
![4,1](\Bilder\ArchivierteTicketsFinden.png)
Anschließend kann das Ticket via Button wiederhergestellt werden.
Ein Admin kann das Ticket hier auch löschen. Diese Option ist
endgültig!
![4,2](\Bilder\ArchivierteTicketsFinden.png)
